# ErrorPage / EmptyBlock / PopoverPanel

```jsx
<ErrorPage icon={<Icon name="CloudX" size={34} />} title="Error 404 page not found"
  message="Sorry, we couldn't find the page you're looking for."
  action={<Button>Back to home</Button>} />
```

No nav rail, no illustration — a glyph, a title, one line, one contained action, centred in the
viewport (C7). `EmptyBlock` is the same idea inside a page, popover or modal; `PopoverPanel`
is the elevation-8 panel a top-bar icon opens (D1).
