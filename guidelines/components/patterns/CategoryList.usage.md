# CategoryList

```jsx
<CategoryList edit={<Icon name="PencilSimple" size={18} />} items={[
  { icon: <Icon name="PaperPlaneTilt" size={20} />, label: 'Advertising & Marketing',
    children: [{ label: 'Test', editable: true }] },
]} />
```

The accounting mapping list: category rows carry the category glyph, subcategory rows indent to
54px and expose a pencil. Same shape on VAT Rates, Cost Centers & Units and Accounts.
