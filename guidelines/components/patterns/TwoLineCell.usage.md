A table cell with a primary value over a quieter second line.

```jsx
<TwoLineCell primary="Amadeus Cytric Pay Wallet" secondary="Amadeus Cytric Pay Wallet" />
```

Observed pairs: program name + code (INT-05), bank name + IBAN (INT-14), posting date + value date (INT-07), card label + last four. The same shape is used for two-line column **headers**, so a header and its cells stay on one grid. The second line is omitted entirely when empty rather than reserving space.
