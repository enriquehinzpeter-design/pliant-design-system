# 04 — Interaction patterns

- **FormDialog** — narrow (~390px): h6 title, stacked label-above fields, radio question rows, footer text-Cancel + contained confirm disabled-until-valid; no X, no dividers. Variants observed: Invite member, Create team, Add organization (with field+adjacent action button "Fetch", inline escape link "Add manually").
- **WizardDialog** — two-pane: tinted #f5f5f0 left step rail (active step = near-black left indicator + helper text) + main pane with selectable option rows (icon + label + "Learn More" + radio) or stacked fields; Cancel + Continue. Variants: Request card, Add Card Variant (Basic Info/Attributes/Summary).
- **CopyRowsDialog** — informational: explanatory bullets + bold warning, select, in-dialog underline tabs, overline section + "Copy all", label/value rows with copy buttons, single "Done".
- **Workspace modal** — near-fullscreen (Receipt Inbox): title+X, underline tabs, right-aligned meta with copy, search+filter+count, grid/list toggles.
- **Record drawer** — 600px right, NO scrim: header (icon/title + StatusBadge, context chips, settings icon + X), stacked info alerts with action links, uppercase section labels, boxed label/value rows, comment row with pencil, accordions at bottom. Variants: transaction, card detail (large CardRender + limit rows), member (contact/teams/cards mini-tiles with usage bars).
- **Filter drawer** — right, WITH scrim: collapsible checkbox sections (labels = colored status tokens), select sections, dates field, sticky "Reset all" (disabled pristine) + contained Apply. Toolbar shows active state: Filter button gains count + solid fill, dismissible filter-value pills row below.
- **Tables** — status as uppercase tinted label ABOVE amount (PENDING blue, DECLINED red + struck amount); card cells = in-app icons; limit meters "0 GBP / 5,100 GBP" + thin progress; sortable arrows; two-line headers with Configure columns for export tables; two-line ledger cells (posting/value date, purpose/type); **RowActions** approvals (red "Block" + teal "Authorize" contained in-row → tinted "Authorized" badge).
- **Other**: SegmentedToggle (pill pair, black active), InlineEditableValueChip ("Account type: Prefund ✎"), HeaderStat (right-aligned overline + large value), ToggleCard stacks (label + info + switch, disabled state), stat-columns settings sections, feature-module illustrated cards, integrations marketplace cards, team cards, wallet card-grid with ghost add tile, account summary cards, 404 page, popover empty states.
