# 07 — Content & voice

- Tone: terse, utilitarian, confident. No emoji. No exclamation marks in product UI.
- **Sentence case everywhere** (buttons, titles, labels); uppercase only for table headers, overlines, micro-labels.
- Terminology: **Cardholder** (not user), **Terminate** (a card, not delete), **Member** (org person), plain use of finance jargon (SEPA, IBAN, VAT).
- Formats: money per-account currency (GBP/EUR/USD — never hardcode one), two decimals, thin negative `-2.00 GBP`; dates `17 Jun 2026` in tables, `12.03.2026` in form fields (German convention), timestamps with seconds in ops file lists.
- Empty states: circled icon + short sentence — observed copy: "No transactions available yet." / "No data available yet." / "No transactions to review." / "No unmatched receipts." / "No Bank accounts connected" / "No notifications so far".
- Regulatory footer (external app): "Pliant cards are issued by Pliant Oy pursuant to license by VISA Europe Limited…"
