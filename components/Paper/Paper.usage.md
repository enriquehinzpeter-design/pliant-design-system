The base surface every panel, card, menu and dialog is built on.

```jsx
<Paper variant="outlined" style={{ padding: 16 }}>…</Paper>
<Paper variant="tinted" style={{ padding: 24 }}>Read-only summary</Paper>
```

Pliant strongly favours `variant="outlined"` for in-page panels; elevation is reserved for overlays (menus 8, dialogs 24).
