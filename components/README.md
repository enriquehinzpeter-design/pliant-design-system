# Components — `@pliant/ui`

Generated by `scripts/sync/extract-components.mjs` from `infinnity-frontend` `packages/ui/src`. Do not edit these files by hand — corrections belong in the codebase (for anything mechanical) or in `scripts/sync/component-notes.json` (for guidance), so they survive the next sync.

**88 components.** 66 are re-exported straight from MUI (4 of those widen MUI's prop unions with Pliant-only values); 22 are Pliant wrappers with their own code. 49 have Storybook stories. 25 are restyled by a theme override module.

Grouping extends `docs/03-components.md`, which names Core, Data, Feedback, Forms, Icon, Navigation and Card art. Those groups do not cover the whole export surface (MUI layout primitives, transition helpers and overlay parts are all exported too), so **Layout**, **Overlays** and **Transitions** were added here. Icon and Card art hold no `@pliant/ui` components at all — icons ship from `@pliant/icons` (see `docs/02-iconography-and-assets.md`) and card artwork is app-level, not library.

**Where the restyling lives.** Almost none of these components carry Pliant styling in their own file. The look comes from `createTheme` plus 25 override modules, so each doc below inlines the override module that applies to it verbatim — that is the real answer to "why does this look the way it does". A component whose "Pliant restyling" section says *None* is MUI's default, restyled only by palette, typography and radius.
