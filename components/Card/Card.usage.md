Groups related content into a bounded surface — card detail panels, integration tiles, plan summaries.

```jsx
<Card>
  <CardMedia image="assets/hero.jpg" height={180} />
  <CardContent>
    <Typography variant="subtitle2">Pliant Visa Platinum</Typography>
    <Typography variant="body2" color="text.secondary">Physical · •• 4821</Typography>
  </CardContent>
</Card>
```

Default is `outlined` — reach for elevation only when the card floats over other content.
