Read-only key/value row in an outlined paper — the Pliant way to present a summary field that is not editable. Covers both `PaperLabeledValue` and `InfoBox` from the source.

```jsx
<PaperLabeledValue label="Available limit" value="€8,420.00" />
<PaperLabeledValue label="IBAN" value="DE89 3704 0044 0532 0130 00" variant="thin" />
```

Label is 12px `caption`/secondary, value is 14px `body2`/primary, right-aligned and never wrapped.
