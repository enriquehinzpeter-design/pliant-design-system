Inline text link — also the correct control for a text-styled action, rendered as a `<button>` with no href.

```jsx
<Link href="/cards/1234">Pliant Visa •• 4821</Link>
<Link onClick={resend}>Resend invitation</Link>
```

Underline appears on hover only by default. Focus-visible draws a 2px primary outline at 2px offset with a 2px radius.
