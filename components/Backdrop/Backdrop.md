# Backdrop

**Group:** Overlays · **Kind:** MUI re-export (`@mui/material/Backdrop`)

> Synced from `infinnity-frontend` `packages/ui/src/components/Backdrop/index.tsx`.

Unstyled MUI backdrop. For a loading state over a section, use `LoaderWithOverlay`, which composes this with a spinner.

## Import

```tsx
import { Backdrop } from '@pliant/ui';
```

## API

Re-exported from `@mui/material/Backdrop`. Props are MUI's `BackdropProps` — this library adds no props of its own.

## Pliant restyling

None. This component inherits the theme (palette, typography, `shape.borderRadius`) but has no component-level override module, so its MUI defaults stand.
